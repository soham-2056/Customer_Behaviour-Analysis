# Customer Shopping Behavior Analysis

## 1. Overview
This project focuses on analyzing customer shopping behavior to identify purchasing trends, customer preferences, and business insights. It uses Python, SQL, and Power BI to transform raw customer data into meaningful insights and interactive visualizations.

## 2. Dataset
The dataset contains customer shopping information, including:
- Customer demographics
- Product categories and purchases
- Purchase amounts
- Discounts and promotions
- Review ratings
- Shopping frequency and preferences

## 3. Tools & Technologies
- **Python:** Data cleaning, preprocessing, and Exploratory Data Analysis (EDA).
- **Pandas & NumPy:** Data manipulation and analysis.
- **SQL Server:** Data querying and business analysis.
- **Power BI:** Interactive dashboards and data visualization.

## 4. Project Workflow

1. **Data Loading:** Imported the dataset into Python using Pandas.
2. **Data Cleaning:** Handled missing values, duplicates, and inconsistent data.
3. **Exploratory Data Analysis:** Identified customer trends, purchasing patterns, and product preferences.
4. **SQL Analysis:** Performed SQL queries, aggregations, joins, and customer segmentation to extract business insights.
5. **Power BI Dashboard:** Created interactive dashboards to visualize sales, customer behavior, product performance, and revenue.


## 5. Dashboard
The Power BI dashboard provides insights into:
- Customer demographics and purchasing behavior.
- Revenue and purchase trends.
- Product category performance.
- Discount usage and customer preferences.
- Customer segmentation and review ratings.

## 6. Key Results
- Identified important customer purchasing patterns.
- Analyzed product performance and revenue trends.
- Evaluated discount usage across product categories.
- Generated insights to support data-driven business decisions.

## 7. Conclusion
This project demonstrates practical skills in data analytics, data cleaning, SQL querying, exploratory data analysis, and dashboard development. It highlights how data-driven insights can help businesses understand customer behavior and improve decision-making.


**Project Domain:** Data Analytics

**Technologies:** Python | SQL | Power BI | Pandas | NumPy
